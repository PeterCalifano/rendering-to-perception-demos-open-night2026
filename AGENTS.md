# Demo repository instructions

Follow the source, review, and commit rules in `PLAN.md`. Preserve external checkout changes. Commit only this repository, and never push. Stop for a critical physical rendering design change or before any external repository source edit.

Use C++20, Doxygen for public APIs, physical unit suffixes, small functions, and concise imperative comments for non-obvious implementation steps. Format C++ with the root `.clang-format`. Run focused validation and inspect the entire staged diff before each stage commit.
